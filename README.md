# BaseFinder (Fabric, Minecraft 1.21.11)

Клиентский мод: показывает на мини-карте чанки, где есть сундуки, бочки и жители.

Команды: `/basefinder toggle`, `/basefinder threshold N`, `/basefinder list`.

Сборка: вкладка Actions -> последний запуск -> Artifacts -> basefinder-jar.
Нужен Fabric API в папке mods.
