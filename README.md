# BaseFinder (Fabric, Minecraft 1.21.11)

Клиентский мод для поиска потерянной базы: ищет чанки с сундуками, бочками, шалкерами и жителями.

- Запоминает найденные базы в файл (отдельно для каждого мира), они остаются после перезахода.
- Метки с именами, стрелка и расстояние (с высотой) до ближайшей базы или выбранной метки.
- Подсветка в мире: столб до верха мира и рамка вокруг находок; цвета настраиваются.
- Мини-карта чанков в углу экрана.

Клавиши (меняются в настройках управления): B - вкл/выкл, N - подсветка в мире, M - метка здесь, V - следующая цветовая схема.

Команды: `/basefinder help`.

Готовый .jar: раздел Releases (latest). Нужен Fabric API в папке mods.
