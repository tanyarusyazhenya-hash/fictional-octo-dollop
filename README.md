# BaseFinder (Fabric, Minecraft 1.21.11)

Клиентский мод: ищет загруженные чанки с сундуками, бочками, шалкерами и жителями.
Показывает мини-карту, подсвечивает чанки в мире (красный столб до верха мира + золотая рамка вокруг находок) и пишет координаты с высотой Y.

Команды: `/basefinder list`, `/basefinder threshold N`, `/basefinder world`, `/basefinder toggle`.

Готовый .jar: раздел Releases (latest). Нужен Fabric API в папке mods.
